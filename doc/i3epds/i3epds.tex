\section{Algorithms \& Complexity}
  Current accelerator topologies aim to maximize parallelization, for instance: the TPU uses the \texttt{im2col} algorithm which re-organizes the input and kernel into matrices such that their multiplication is equivalent to the convolution of their original signals~\cite{vasudevan2017parallel}. While this method enables highly-parallelized systolic array implementations, its hardware cost scales drastically with the size of the convolution kernel~\cite{lera2023hardware}. 

  Regarding kernel size, a larger number of layers with smaller kernels can provide the same receptive field as a single layer with a large kernel, at a lower processing cost~\cite{simonyan2014very}.
